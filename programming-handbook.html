دليل المبرمج من الصفر

مرجع عملي للوحة المفاتيح، وكتابة الكود، والملفات، وسطر الأوامر، وتشخيص الأخطاء. استخدمه بجانب الدروس وارجع إليه كلما احتجت.

1. لوحة المفاتيح ورموز البرمجة

تختلف أماكن بعض الرموز حسب لغة لوحة المفاتيح وتخطيطها. غيّر بين العربية والإنجليزية من إعدادات اللغة أو اختصار النظام. عند كتابة الكود استخدم الإنجليزية غالبًا، وتأكد من ظهور الرمز الصحيح قبل تشغيله.

( )

الأقواس العادية: استدعاء الدوال وتجميع العمليات.

[ ]

الأقواس المربعة: عناصر القوائم والوصول إلى عنصر.

{ }

الأقواس المعقوفة: كتل أو كائنات حسب اللغة.

' '

علامة اقتباس مفردة: إحاطة نص في لغات كثيرة.

" "

علامة اقتباس مزدوجة: إحاطة النصوص.

:

النقطتان: بداية كتلة في Python، وتستخدم في سياقات أخرى.

;

الفاصلة المنقوطة: نهاية تعليمة في بعض اللغات.

,

الفاصلة: الفصل بين العناصر أو الوسائط.

.

النقطة: خصائص الكائنات والكسور العشرية.

=

إسناد قيمة لمتغير في سياقات كثيرة.

==

مقارنة قيمتين في لغات كثيرة؛ ليست مثل =.

!=

لا يساوي.

+ - * /

عمليات حسابية أساسية.

#

تعليق في Python، ويستخدم في سياقات أخرى.

_

شرطة سفلية داخل أسماء مثل student_name.

\

شرطة مائلة عكسية، لها استخدامات خاصة في النصوص والمسارات.

قواعد كتابة مهمة

  • انتبه للفرق بين الحروف الكبيرة والصغيرة: name وName اسمان مختلفان في Python.
  • لا تخلط بين علامات الاقتباس المستقيمة وعلامات التنصيص المزخرفة.
  • استخدم مسافات بادئة ثابتة، ولا تخلط Tab والمسافات عشوائيًا.
  • لا تضع مسافة داخل اسم المتغير؛ استخدم student_name.
  • احفظ الملف بامتداد مناسب مثل .py أو .html.

2. اختصارات ستستخدمها كل يوم

التحرير والكتابة

  • Ctrl + C نسخ النص المحدد.
  • Ctrl + V لصق.
  • Ctrl + X قص.
  • Ctrl + Z تراجع.
  • Ctrl + Y إعادة العملية في تطبيقات كثيرة.
  • Ctrl + A تحديد الكل.
  • Ctrl + S حفظ الملف.
  • Ctrl + F بحث داخل الملف.

التنقل في المحرر

  • Home / End بداية أو نهاية السطر.
  • Ctrl + ← / → الانتقال بين الكلمات.
  • Shift + Arrows تحديد النص أثناء التنقل.
  • Tab إزاحة السطر أو إكمال المسافة البادئة.
  • Ctrl + Enter تشغيل الكود في محرر DOMA.
  • Ctrl + / تعليق السطر في محررات كثيرة.

3. تعلّم Terminal بالتجربة

الـTerminal واجهة نصية لكتابة أوامر للنظام. الصندوق التالي محاكاة تعليمية آمنة داخل الصفحة؛ لا ينفذ أوامر على جهازك ولا يتصل بخادم الموقع.

DOMA Training Terminal v1.0
محاكاة تعليمية — اكتب help لعرض الأوامر.
student@doma:~$

جرّب: pwd لمعرفة المجلد الحالي، ls لعرض الملفات، mkdir لإنشاء مجلد تدريبي، وcd للدخول إليه.

أوامر شائعة على أنظمة Unix

  • pwd عرض المسار الحالي.
  • ls عرض الملفات والمجلدات.
  • cd folder تغيير المجلد.
  • mkdir name إنشاء مجلد.
  • touch file.py إنشاء ملف فارغ.
  • cat file.py عرض محتوى ملف نصي.

أوامر شائعة على Windows

  • cd عرض أو تغيير المجلد الحالي.
  • dir عرض الملفات والمجلدات.
  • mkdir name إنشاء مجلد.
  • type file.txt عرض محتوى ملف نصي.
  • cls مسح الشاشة.

4. طريقة منظمة لتصحيح الأخطاء

  1. اقرأ رسالة الخطأ كاملة. ابحث عن نوع الخطأ واسم الملف ورقم السطر.
  2. ابدأ بأول خطأ. قد تكون الأخطاء التالية نتيجة للخطأ الأول.
  3. افحص السطر وما حوله. راجع الأقواس والاقتباسات والنقطتين والمسافات البادئة وأسماء المتغيرات.
  4. تتبّع القيم. اطبع المتغيرات أو استخدم أدوات Debugger لمعرفة قيمها أثناء التنفيذ.
  5. غيّر شيئًا واحدًا في كل مرة. حتى تعرف أي تعديل أصلح المشكلة.
  6. أعد الاختبار. جرّب حالة عادية، وحدّية، ومدخلًا غير متوقع.
  7. اكتب سبب المشكلة. تدوين السبب والحل يمنع تكرار الخطأ.

SyntaxError

مشكلة في قواعد كتابة اللغة. راجع الأقواس والاقتباسات والنقطتين والكلمات المحجوزة.

print("Hello"

المثال ناقصه قوس إغلاق.

NameError

استخدمت اسم متغير غير معرّف أو كتبت اسمه بطريقة مختلفة.

print(user_name)

تأكد أنك أنشأت المتغير بنفس الحروف.

TypeError

عملية لا تناسب نوع البيانات، مثل جمع نص مع رقم دون تحويل.

"Age: " + str(13)

حوّل الرقم إلى نص عند دمجه مع نص.

IndentationError

المسافة البادئة غير صحيحة أو غير متناسقة، خصوصًا داخل if والحلقات والدوال.

if score >= 50:\n print("Pass")

IndexError

طلبت عنصرًا خارج حدود القائمة. تذكر أن الفهرسة تبدأ غالبًا من صفر.

items = ["A", "B"]

الفهارس الصحيحة هنا 0 و1.

Logic Error

الكود يعمل لكنه يعطي نتيجة غير صحيحة. راجع الخوارزمية، ترتيب العمليات، وشروط المقارنة.

5. قاموس المبرمج السريع

Code: تعليمات البرنامج.

Syntax: قواعد كتابة اللغة.

Variable: اسم يشير إلى قيمة.

Function: مجموعة تعليمات قابلة لإعادة الاستخدام.

Loop: تكرار تنفيذ تعليمات.

Condition: شرط يحدد مسار التنفيذ.

Compiler: أداة تحول الكود إلى صيغة قابلة للتنفيذ.

Interpreter: يشغّل التعليمات وفق آلية اللغة.

Bug: خطأ في البرنامج.

Debugging: العثور على الخطأ وإصلاحه.

Test Case: مدخلات ونتيجة متوقعة لاختبار الحل.

Version Control: تتبع تغييرات المشروع.
